Práticas que aproximam pessoas e tecnologia

Este projeto acadêmico demonstra como ferramentas e processos podem transformar um fluxo de desenvolvimento desorganizado em uma rotina mais colaborativa e confiável.

⌘

Versionamento

Branches, commits e Pull Requests organizam a evolução do código e facilitam a revisão entre os integrantes.

▣

Containerização

O Docker padroniza o ambiente de execução e reduz diferenças entre as máquinas da equipe.

↗

Integração contínua

O GitHub Actions automatiza verificações para aumentar a segurança a cada nova alteração.
