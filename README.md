# 🚀 CodeFactory Solutions - Projeto DevOps

## 📝 Descrição do Projeto
Este projeto faz parte de uma consultoria de transformação digital para a empresa **CodeFactory Solutions**. O objetivo é implementar a Cultura DevOps para resolver problemas de falta de padronização, atrasos em entregas e dificuldades na integração de novos desenvolvedores.

## 🎯 Objetivo
Demonstrar na prática a utilização de ferramentas de versionamento (Git/GitHub), containerização (Docker) e Integração Contínua (CI) para otimizar o fluxo de desenvolvimento de software.

## 🛠️ Tecnologias Utilizadas
*   **Versionamento:** Git & GitHub
*   **Containerização:** Docker
*   **CI/CD:** GitHub Actions
*   **Linguagem:** HTML, CSS e JavaScript (Base para o site da empresa)
*   **Documentação:** Markdown & GitHub Wiki

## 📁 Estrutura de Pastas
```text
/
├── .github/workflows/  # Configurações de CI/CD
├── src/                # Código fonte da aplicação
├── docker/             # Arquivos de configuração do Docker
├── docs/               # Documentação adicional
├── README.md           # Instruções principais
└── LICENSE             # Licença do projeto
⚙️ Instruções de Instalação e Execução
Clone o repositório: git clone https://github.com/izabelaxavier/CodeFactory-Solutions.git

```
